Package Central

Automated document packaging for Adobe InDesign. Watch hot folders and package files effortlessly, offloading the process from InDesign to run fully unattended. Operators stay free, production stays smooth.

Key Advantages

Hot Folder Automation

Collect InDesign documents automatically from watched folders. Start monitoring on launch with the new version 1.14 setting—no manual intervention required.

Operator Freedom

Offload packaging entirely from operator stations. Keep creative workflows uninterrupted while Package Central handles the heavy lifting in the background.

Complete Exports

Generate PDF and IDML files automatically with every package. Ensure all fonts, images, and links are collected precisely, ready for handover.

Smart Notifications

Receive email alerts at every stage—processing start, completion, or issues. Stay informed without constant monitoring, even in unattended mode.

Customizable and Logged

Tailor package folder names to your workflow. Track every action with detailed process logs for full transparency and auditing.

How It Works

1. Set Up Hot Folders

Define watched folders in Package Central. Drop InDesign files in—processing begins instantly, with auto-start on launch.

2. Automatic Packaging

Package Central collects files, gathers links and fonts, and exports PDF/IDML. Runs unattended, freeing InDesign completely.

3. Receive Notifications

Get email updates on progress and completion. Access logs for details anytime.

4. Retrieve Packages

Find organized packages in custom-named folders, fully self-contained and ready for delivery.
